# Sportsmonks
 testing machine learning on sports data provieded by sportmonks.

the project uses the 00 sportmonks data to create and fetch almost everything from the sportmonks data API and creating tables and a database.

the 000 sportmonks data then runs to fetch updates or missing data from when last collected to have the best dataset with most data.

the 000 feature selection can be ran to both train and test diffrent models, the same applies for 001 feature and training, sportmonks modelling and finally the 000 neural sportmonks.



these have been tested, provieded and ran to be able to showcase the prototype of the upcoming app, which is going to include multiple sports, like tennis, basketball, baseball, icehockey and american football in the long run.

For now it is displaying the predicted games, the confidence, and hopefully the tab with the statistics will be completed as well.

the files one_done, two_done, three_done, is files to showcase a continue optimization for prediction models, the note book will be cleaned, and set up, in a structtural manner later on for an easy overview.

the current notebooks are able to work with the database, but not fetch all new data, as the subscriptions are expensive and will be turned on later again.



The whole idea behind the "easyBet" or "betadvicer", is the long run. To create a hub of statistics showcasing all kinds of views, for the everyday punter or the skilled bettor, to use these to apply valueable decisions.

The other tabs should be the standings of all leagues, the tab with prediction scores, and applied ROI for those matches.
the models performance should be visible for the user, so it can be seen what the actual performance is vs the trained and tested performance
